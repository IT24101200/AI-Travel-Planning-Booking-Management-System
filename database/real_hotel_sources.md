## Room stock behavior

Only confirmed bookings consume rooms, for overlapping check-in/check-out dates. Checkout is exclusive. Availability uses peak concurrent occupancy, so sequential stays do not consume stock twice. Approval rechecks capacity inside a transaction; conflicting proposals cannot both be confirmed. Cancellation/rejection and checkout dates release availability without changing the physical TotalRooms field.
